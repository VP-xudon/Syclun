# Synth-OOP 语法高亮插件 · 打包教程

本教程说明如何把 `vscode-synth-oop/` 目录里的扩展源文件，打包成 VSCode 扩展包
`.vsix`，以及如何安装 / 上架。打包产物的输出位置固定为项目根目录的 **`build/`**
（`synth-oop-<版本>.vsix`），不再留在扩展目录内。

> 环境要求：
> - 仅「打包」需要任意带 `zipfile` 的 Python（本机离线即可，无需联网、无需第三方依赖）。
> - 如需用官方 `vsce` 上架市场，另需 Node.js / npm 与联网（见末尾）。
> - 安装 / 运行扩展需要 [Visual Studio Code](https://code.visualstudio.com/)。

---

## 一、离线打包（本项目采用的方式，推荐）

本仓库不依赖联网工具，使用 `build_vsix.py` 按 VSCode 标准 **VSIX v3（OPC/ZIP）**
规范离线生成扩展包。脚本读取 `package.json` 里的 `name` 与 `version` 自动命名产物。

1. 在**仓库根目录**打开终端，运行打包脚本：

   ```bash
   python vscode-synth-oop/build_vsix.py
   ```

   > 若系统未把 `python` 加入 PATH，用本机 Python 可执行文件绝对路径执行该脚本即可。
   > 脚本已随仓库提供（`vscode-synth-oop/build_vsix.py`），路径由脚本自身位置推导，
   > 因此在任何克隆位置都能直接使用。

2. 脚本会：
   - 校验 `package.json` 可解析并读取 `name` / `version` / `publisher`；
   - 把以下文件打进扩展包：`package.json`、`language-configuration.json`、
     `syntaxes/synth-oop.tmLanguage.json`、`README.md`、`打包教程.md`、
     `examples/demo.syn`、`icons/synth-icon.png`、`LICENSE`；
   - 生成 `[Content_Types].xml` 与 `extension.vsixmanifest`，并写入 `extension/` 目录结构；
   - 做 ZIP 完整性自检并打印条目清单。

3. **产物位置**：脚本直接把包写到项目根目录的 `build/` 下：

   ```
   V:/SynthOOP/Syclun/build/synth-oop-1.3.5.vsix
   ```

   （文件名随 `package.json` 的 `version` 自动变化；扩展源目录内不再保留任何 `.vsix`。）

打包后即可进入下一节的安装步骤。改了语法 / 配置后重新跑一次脚本即可重新生成。

## 二、官方打包（可选，用于上架 Marketplace）

若要走官方发布流程，可用微软官方工具 `vsce` 生成 `.vsix`（产物同样是一个
标准扩展包，可与离线脚本产物互相替换安装）：

```bash
npm install -g @vscode/vsce
cd V:/SynthOOP/Syclun/vscode-synth-oop
vsce package        # 生成 synth-oop-<版本>.vsix
```

> 注：本仓库默认采用「一、离线打包」，成品同样符合 VSIX 规范、可直接安装；
> 离线脚本只是避免联网安装 `vsce`。二者产物格式一致。

## 三、从打包产物安装

`.vsix` 是 VSCode 标准扩展包，安装方式任选其一。以下以 `build/` 下产物为例。

### A. 图形界面安装
1. 打开 VSCode，切到「扩展」面板（`Ctrl+Shift+X`）。
2. 点击右上角 `···` → **「Install from VSIX…」**。
3. 选择 `V:/SynthOOP/Syclun/build/synth-oop-1.3.5.vsix`。
4. 按提示 **重新加载窗口（Reload Window）**。

### B. 命令行安装
```bash
code --install-extension "V:/SynthOOP/Syclun/build/synth-oop-1.3.5.vsix"
```
若 `code` 未加入 PATH，用其完整路径，例如：
```bash
"/c/Users/你的用户名/AppData/Local/Programs/Microsoft VS Code/bin/code" --install-extension "V:/SynthOOP/Syclun/build/synth-oop-1.3.5.vsix"
```

### C. 解压到扩展目录（免 CLI）
把 `.vsix` 当 ZIP 解压，将内部 `extension/` 的内容整体放入：
- Windows: `%USERPROFILE%\.vscode\extensions\synth-oop\`
- macOS / Linux: `~/.vscode/extensions/synth-oop\`
重启 VSCode。

### D. 扩展开发宿主（调试 / 改语法）
用 VSCode 打开 `vscode-synth-oop/`，按 `F5`（Run Extension），在新开的宿主窗口中打开
任意 `.syn` / `.synl` / `.syni` 文件即见高亮；改完语法按 `Ctrl+R` 重新加载。

## 四、验证安装成功

1. 打开任意 Synth-OOP 文件（如 `vscode-synth-oop/examples/demo.syn`）。
2. 右下角语言模式应为 **Synth-OOP**。
3. 关键字（`@` `$` `#` `!`）、类型（`std::Number` 等）、注释、字符串等应呈现对应着色；
   `.syn` / `.synl` / `.syni` 文件在资源管理器中显示统一图标。

> 本插件采用 VSCode 标准 TextMate 作用域，**实际颜色由当前主题（Light+/Dark+ 等）决定**，
> 切换主题即可整体换色，不写死任何颜色。

---

## 五、卸载

- 方式 A/B/C：在「扩展」面板搜索 `Synth-OOP`，齿轮图标 → Uninstall。
- 方式 C 手动解压：删除放入的 `synth-oop` 扩展目录并重启 VSCode。

## 六、提交到 VS Code 插件库（发布上架）

要让别人在 Marketplace 搜索安装，需走官方发布流程（需联网与 `vsce`）：

1. 打开 <https://marketplace.visualstudio.com/manage>，用 Microsoft / GitHub 登录，
   **Create publisher**，发布者 ID 填 **`VP_xudon`**（须与 `package.json` 的 `"publisher"` 一致）。
2. 在发布者管理页 → **Personal access tokens** → **New**，Scopes 勾选 `Marketplace` 的 `Manage`，
   保存仅显示一次的 PAT。
3. 在扩展目录执行：

   ```bash
   vsce login VP_xudon     # 粘贴 PAT
   vsce package            # 本地生成 .vsix 先验证
   vsce publish            # 发布到 Marketplace
   ```

   发布所需字段本插件已齐备：`publisher`(VP_xudon)、`icon`(icons/synth-icon.png)、
   `license`(MIT)、README、`LICENSE` 文件。

> 离线脚本生成的 `.vsix` 与官方 `vsce package` 结构一致，可直接安装 / 上架；
> 只是**上架动作本身**必须由 `vsce publish` 走官方流程（需上面的 PAT 与发布者账号）。

## 七、常见问题

- **离线脚本依赖网络吗？** 不依赖，纯 Python 标准库 `zipfile`。
- **产物在哪？** 固定在 `build/synth-oop-<版本>.vsix`；扩展目录内不再保留 `.vsix`。
- **双击 `.vsix` 没反应？** 用「Install from VSIX…」或命令行安装，勿直接双击。
- **`code` 命令找不到？** VSCode 内 `Ctrl+Shift+P` → `Shell Command: Install 'code' command in PATH`，
  重开终端。
- **装完没高亮？** 确认扩展名是 `.syn`/`.synl`/`.syni` 之一，且已重新加载窗口。
- **想改配色？** 在 VSCode `settings.json` 的 `editor.tokenColorCustomizations.textMateRules`
  中针对对应标准作用域覆盖即可，无需改动本插件。
